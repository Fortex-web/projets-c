# projets-c

Mes projets pour progresser en C, en parallèle de mes études à l’UTBM.
Pendu : jeu du pendu dans le terminal, 7 essais, gestion des lettres déjà proposées.

Morpion : jeu du morpion contre l’ordinateur dans le terminal (l’ordi gagne quand il peut, bloque les alignements du joueur, puis préfère le centre et les coins), vérification des coups (hors grille, case déjà prise), détection de victoire (lignes, colonnes, diagonales) et match nul.
