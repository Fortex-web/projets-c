# projets-c

Mes projets pour progresser en C, en parallèle de mes études à l’UTBM.
Pendu : jeu du pendu dans le terminal, 7 essais, gestion des lettres déjà proposées.

Morpion : jeu du morpion contre une IA imbattable dans le terminal (algorithme minimax récursif : l’ordi simule toutes les parties possibles et ne perd jamais), vérification des coups (hors grille, case déjà prise), détection de victoire (lignes, colonnes, diagonales) et match nul.
